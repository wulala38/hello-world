
# 图片资源说明
此目录用于存放小程序所需的图片资源。
当前版本使用Iconfont和Emoji作为图标，可正常运行。

如需替换真实图片，请准备以下文件：
- logo.png - 应用Logo (120x120px)
- home.png - 首页图标 (81x81px)
- home-active.png - 首页选中图标 (81x81px)
- levels.png - 关卡图标 (81x81px)
- levels-active.png - 关卡选中图标 (81x81px)
- knowledge.png - 知识库图标 (81x81px)
- knowledge-active.png - 知识库选中图标 (81x81px)
- profile.png - 我的图标 (81x81px)
- profile-active.png - 我的选中图标 (81x81px)
- default-avatar.png - 默认头像 (200x200px)

注意：这些文件是可选的，小程序在没有图片的情况下也能正常运行。
