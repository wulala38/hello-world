# 古物理趣 - 古代物理密室科普助手

## 项目概述

古物理趣是一款配套线下中国古代物理交互式密室的微信小程序，为玩家提供游戏引导、物理知识学习、进度追踪和社交分享等功能。

## 功能模块

### 1. 首页模块
- 项目介绍展示
- 开始体验入口
- 扫码绑定功能
- 科普学习入口
- 古风简洁UI设计

### 2. 蓝牙连接模块
- BLE5.0蓝牙通信支持
- 与密室Arduino机关实时通信
- 连接状态实时显示
- 自动重连机制

### 3. 关卡系统
6大主题关卡：
- 杠杆原理
- 滑轮系统
- 浮力原理
- 光影奥秘
- 声学原理
- 力学应用

每个关卡包含：
- 场景图
- 通关目标
- 背景介绍

### 4. 智能提示系统
- 30秒：原理图文提示
- 60秒：分步操作指引
- 手动触发功能

### 5. 科普知识库
- 对应各关卡的古代物理原理
- 文字说明
- 图解展示
- 动画视频

### 6. 互动答题
- 每关2-3道题目
- 答对解锁知识卡片
- 即时反馈

### 7. 进度成就系统
- 关卡进度追踪
- 徽章收集
- 游玩数据统计

### 8. 打卡分享
- 古风海报生成
- 微信分享
- 保存相册

### 9. 我的页面
- 个人信息
- 历史记录
- 收藏夹
- 反馈建议

## 技术架构

### 前端框架
- 微信小程序原生开发
- WXML + WXSS + JavaScript

### 页面路由
- tabBar底部导航
- 页面跳转

### 蓝牙通信
- wx.createBLEConnection
- wx.writeBLECharacteristicValue
- wx.onBLECharacteristicValueChange

### 数据存储
- 本地存储：wx.setStorageSync
- 云开发（可选）

## 目录结构

```

├── app.js
├── app.json

├── pages/

│   ├── level-detail/   # 关卡详情

│   ├── quiz/           # 互动答题
│   ├── profile/        # 我的页面

├── utils/             # 工具函数

```

## 设计规范

### 色彩方案
- 主色：#8B4513（古铜色）
- 辅色：#F5DEB3（麦色）
- 强调色：#DAA520（金色）
- 背景色：#FFF8DC（米色）
- 文字色：#2F1810（深褐色）

### 字体
- 标题：思源宋体或系统默认
- 正文：系统默认字体

### 交互设计
- 古风科技感结合
- 流畅的页面切换
- 响应式适配

## 开发规范

- 使用ES6+语法
- 模块化开发
- 组件复用
- 注释完整
